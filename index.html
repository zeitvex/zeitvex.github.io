在线仿真 · 浏览器里的真策略

同一份 MJCF、同一份 53 维观测契约、同一份 ONNX 权重。左侧选择策略与地形，W/S 前后、A/D 横移、Q/E 转向， 或打开「指令」面板用滑杆遥控。切换策略时按真机运行时的 1.0 秒线性混合过渡。

首次加载约 25 MB（MuJoCo WASM + ONNX Runtime Web，之后走浏览器缓存）。建议桌面端 Chrome / Edge / Firefox 最新版。 若嵌入窗口操作不便，请 全屏打开。

系统契约 · 训练 / 仿真 / 真机同一份

观测与动作的每一维顺序、缩放、默认站姿都由 sim2real_ros2_v3 的部署契约 （deployment_contract.hpp）固化，训练配置、浏览器仿真、真机 C++ 运行时三方同源。

比赛双策略

Rough 主策略 · model_6800

比赛最终部署的粗糙地形策略，覆盖台阶、随机网格、坡面与高墙混合地形。1050 分成绩局的实机加载件，ONNX 输入 [1,53] → 输出 [1,16]，与真机 TensorRT 引擎同权重。

高墙策略 · model_84

Robocon 高墙环节专用策略，针对 0.10–0.35 m 重复横墙训练。在试玩区选择「五道高墙」地形即可看到真实的攀爬：机身冲上 0.30 m 墙顶、姿态恢复后继续前进。

训练 · mjlab + PPO

训练主体为 v0.6.0 best 比赛架构：分轴 vx/vy/yaw 跟踪奖励、自适应指令课程、障碍释放课程， 2048 并行环境，物理 200 Hz、策略 50 Hz。

这个站点本身

纯静态 · 零后端

GitHub Pages 托管。仿真 = MuJoCo WebAssembly（物理）+ ONNX Runtime Web（策略推理）+ Three.js（渲染），全部在浏览器内完成，没有任何服务端计算。

网格抽稀

MJCF 原始 STL 共 42.4 MB / 84.8 万三角形，构建期经顶点聚类抽稀至 3.8 万三角形（单文件从 9.2 MB 到 344 KB）。MuJoCo 编译与浏览器渲染共用同一份抽稀结果，首屏数据量下降两个数量级。
